Setting up Server Credentials

Get your credentials and start playing online

1

Get Your Credentials

You need a credentials.bin file to connect to the server.

If you don't have one yet, request beta access and we'll send you the file via email.

2

Save the Credentials

Save your credentials.bin file from the email we send you onto your computer hard drive, making sure to remember the location where your saved it.

(Your download directory could be a good place for this.)

3

Load the Credentials in Game

Launch the game and click "Connect to Server" from the main menu.

Initially you will see 'No credentials found for server connection' near the top of this page.

Click the 'Find credentials file' button to open a file browser, and browse to the location where you saved the credentials.

4

Connect from the Game

Once credentials have been supplied, you should see 'Credentials found', in green, at the top of the page, and there will be a "Connect to Server" button.

Click this button and you'll be connected to the server.

(You should then see a page with 'Multiplayer' at the top, and a bunch of tabs for different server operations.

Ready to Play!

Once connected, you can join public rooms or create private rooms to play with friends.
