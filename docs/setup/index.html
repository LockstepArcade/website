Setting up Server Credentials

Get your credentials and start playing online

1

Get Your Credentials

You need credentials in order to connect to the server.

Credentials are encoded in a 36 charater long text string, which will look something like this: AffTtjwdDNrGmMkPi2ODdO0jjORY8ghnVCKe

(This is not a valid credentials string, but valid credentials will look similar.)

If you don't have credentials yet, request beta access and we'll send credentials by email.

2

Load the Credentials in Game

Launch the game and click "Credentials setup" from the main menu.

This will open a page (or overlay UI, in the web build), where you can paste your credentials string.

Once valid credentials have been entered, you will now be able to connect to the server from the main menu.

Old style credentials

Old style credentials in the form of a credentials.bin file are still supported.

Just follow the steps above, but instead of pasting in credentials text, click the button to browse to the credentials file instead.

3

Connect To the Server

Once credentials have been supplied, the "Connect to Server" button on the main menu should be enabled.

Click this button and you'll be connected to the server.

(You should then see a page with 'Multiplayer' at the top, and a bunch of tabs for different server operations.)

Ready to Play!

Once connected, you can join public rooms or create private rooms to play with friends.
