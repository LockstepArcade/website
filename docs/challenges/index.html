Testing Challenges

A list of testing goals and things you can do with the game, expressed as a list of challenges:

1

Run the game (web client)

Objective: Run the web client

This one's easy, just click this link to run Lockstep Arcade directly in a browser.

Try running on a phone, as well as a desktop/laptop device.

2

Connect to the server (as a guest)

Objective: Get in to the multiplayer UI and see a list of players on the server (which might be just you)

Also easy now. Just click on 'Connect as guest' in the main menu.

3

Complete the Spirits tutorial

Objective: Get a tick on every map in the Spirits tutorial

Once connected, choose single player/campaign, pick Spirits, and start the tutorial. The tutorial is a grid of maps, where beating a map unlocks the maps to its right and below it. Try and complete each of them.

4

Complete the Serpents tutorial

Objective: Get a tick on every map in the Serpents tutorial

Do the same for Serpents.

5

Complete the Neon Swarm tutorial

Objective: Get a tick on every map in the Neon Swarm tutorial

Do the same for Neon Swarm.

6

Start a single player campaign

Objective: Beat the first map of a single player campaign

Choose single player/campaign again, and this time create a single player campaign. The campaign works the same way as the tutorial, with harder maps.

7

Neon Swarm high score

Objective: Get your name on a Neon Swarm high score table

Unlock the 'Cauldrons' map in the Neon Swarm single player campaign, play it, and get on the highscore table.

(High scores get wiped after compatibility breaking releases, so it may be that you are the first player on the high score table, so this might be easy!)

Bonus objectives: Get to the top of the highscore table, and stay there!

8

Complete a campaign

Objective: Complete all the levels in one of the single player campaigns

The campaign for Serpents is perhaps the easiest. Some levels at the end of the Spirits campaign are very challenging.

Bonus objectives: Complete all of the single player campaigns!

9

Play a multiplayer game

Objective: Organise a game with someone else

Play a multiplayer game.

One way to do this is to get a friend to play as well, and connect to the server at the same time.

A second (less sociable) possibility is to start two instances of the game client and play against yourself. :)

10

Additional challenges

Objective: Get a rating for Neon Swarm

Objective: Get a rating for Pilots

Objective: Get to the top of one of the ratings tables!

Objective: Find and report a bug!
