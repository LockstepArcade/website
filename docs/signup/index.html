Request Beta Access

Sign up to receive your credentials file and get notified about updates and new features. The game is currently in early development, and we're looking for players to test and provide feedback!

We'll send you a credentials.bin file via email within 24-48 hours. Make sure to check your spam folder!

What Happens Next?

1

We Process Your Request

After submitting the form, we'll review your request and generate your unique credentials file.

2

Receive Your Credentials

Within 24-48 hours, you'll receive an email with your credentials.bin file attached. Check your spam folder if you don't see it!

3

Download and Play

Download the game client, add your credentials file to the game folder, and start playing!
