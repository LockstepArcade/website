Easy Install (Recommended)

Copy and paste one of these commands to automatically download and extract the game. This avoids browser security warnings.

Windows (PowerShell)

Open PowerShell and paste this command:

irm https://locksteparcade.com/install_windows.ps1 | iex

macOS (Terminal)

Open Terminal and paste this command:

curl -sL https://locksteparcade.com/install_mac.sh | bash

The script downloads the game to your Downloads folder, extracts it, and opens the folder for you.

⚠️ Credentials Required

The game requires a credentials.bin file to connect to the dedicated server.

If you don't have credentials yet, request beta access here and we'll send you the file via email.
