iOS Audio Diagnostic

Each test makes a 440 Hz beep for about half a second. Tap them in order and note which ones you can actually hear. The log records what each test did.

Before starting: note the position of the Ring/Silent switch, and turn the volume up. While test 10 is looping, press a volume button — the on-screen volume HUD says either Ringer or Media, and which one it says is itself a result worth recording.
