Installation Steps

1 Open PowerShell (find this by typing "powershell" in the Windows search bar)
2 Paste the command above (by right clicking inside PowerShell), and press Return
3 The script will download, extract, and open the game folder
4 Double-click LockstepArcade.exe to run the game

Windows SmartScreen

If Windows SmartScreen appears, click "More info" then "Run anyway".

If you skipped the unblock step, you may also need to unblock the .exe file the same way (Properties → Unblock).

Running in Windows Sandbox

If you're concerned about security, and have a version of Windows that supports this, we recommend running in Windows Sandbox (overview, setup instructions).

1 Download the ZIP file using the button above
2 Extract the ZIP (double-click it in Finder), navigate into extracted directory
3 Attempt to open: Right-click LockstepArcade → select "Open" (this may be blocked by the OS)
4 If blocked: Go to System Settings → Privacy & Security → scroll down to message about LockstepArcade → click "Open Anyway"

Alternative: Remove Quarantine via Terminal

If you're comfortable with Terminal, you can remove the quarantine attribute directly with the following command:

xattr -d com.apple.quarantine LockstepArcade

(Run this in Terminal, in the game folder.)

You should now see the main menu!

You can explore the tutorial and offline features. To play online, you'll need server credentials.
