Setting up Server Credentials

Get your credentials and start playing online

1

Get Your Credentials

You need a credentials.bin file to connect to the server.

If you don't have one yet, request beta access and we'll send you the file via email.

2

Add Credentials to the Game Folder

Copy your credentials.bin file into the same folder as the game executable.

Your game folder should contain:

  • LockstepArcade.exe (or LockstepArcade on Mac)
  • credentials.bin ← your credentials file
  • data/ folder
  • README.md
3

Connect from the Game

Launch the game and click "Connect to Server" from the main menu.

You'll be connected to the lobby where you can join or create game rooms.

Ready to Play!

Once connected, you can join public rooms or create private rooms to play with friends.

Troubleshooting

"Credentials not found"

Make sure credentials.bin is in the same folder as the game executable, not in a subfolder.

"Connection failed"

Check your internet connection. If the problem persists, the server may be temporarily offline—check Discord for status updates.

Can't run the game?

If you're having trouble launching the game itself (security warnings, blocked files), see the download page for platform-specific instructions.

Need credentials?

Request beta access and we'll send you credentials via email.
